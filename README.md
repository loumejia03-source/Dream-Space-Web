# Dream Space 🌌


## ¿Qué es este repositorio?

Este repositorio contiene una página web creativa llamada Dream Space.
Su objetivo es mostrar un espacio digital donde se unen la creatividad,
el arte, la música y la tecnología.


## ¿Para qué sirve?

Sirve para presentar información de manera interactiva utilizando
una página web diseñada con diferentes elementos visuales.


## Tecnologías utilizadas

- HTML5: Para crear la estructura de la página.
- CSS3: Para diseñar los estilos, colores y distribución.
- JavaScript: Para agregar interacción mediante botones.
- GitHub Pages: Para publicar la página web.
